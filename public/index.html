Formats & counting guide+

What you can upload. Word (.docx), PowerPoint (.pptx), selectable-text PDF, Excel (.xlsx / .xls), OpenDocument (.odt / .odp / .ods), RTF, HTML and readable Unicode text. Maximum 3 MB, 100,000 extracted characters and 200 PDF pages. Images and scanned PDFs need OCR first. Export older .doc / .ppt files before uploading.

How words are counted. Text is lowercased; punctuation and whitespace separate tokens. “Don't” becomes “don” and “t”; “12.5” becomes “12” and “5”. Unicode letters and numbers remain. No stopwords are removed. Characters include spaces and punctuation in the extracted text. Spreadsheet formulas are not evaluated; cached values are used when available.

Reading the results. Table share is a word’s percentage of all tokens. A chart bar’s width is relative to the most frequent word. Lookup shows a word’s count and share; it does not filter the table. Minimum occurrences filters the table only. Downloads always contain the complete report.

Document handling. Your document is sent to the Python analysis service for processing without writing it to disk. Visual layout and reading order may differ from the original document.
